# Portfolio

梁可悦的个人求职主页（静态站点，GitHub Pages 托管）。

- 在线地址：https://lky-hjh.github.io/portfolio/
- 技术：纯静态 HTML + CSS，无构建步骤；改完推到 `main` 即生效

## 本地预览

直接双击 `index.html`，或：

```bash
python -m http.server 8000
```
